# PROTOCOL: STIGMA — 1막: 낙인

> **PROTOCOL: STIGMA**는 시스템에 의해 폐기된 불량 코드 N-404가 되어 데드존에서 살아남고, 첫 거점을 선언하기까지를 그리는 **하드코어 생존 사이버펑크 텍스트 RPG**입니다.

> 완벽한 안전지대는 없다. 무자비한 불모지를 무력으로 청소하든, 감시망을 속이든 — 당신만의 생존 공간을 직접 개척하고 사수하라.

![T_RPG Banner](assets/banner.png)

---

## 세계관

- **네오 아크 (5%)** — 마스터 AI와 지배 계급이 통제하는 초고도 가상 도시. 인류의 95%를 격리하라는 연산 결과로 세워졌다
- **데드존 (95%)** — 방사능 폭풍과 기계 괴수가 도는 아날로그 폐허. 구시대 유물이 묻혀 있는 기회의 땅이기도 하다
- 당신은 네오 아크 실험실에서 '불량 코드'로 분류되어 데드존 최외각 **폐기물 처리장**에 버려졌다. 시스템이 제공하는 안전 구역은 어디에도 없다

## 1막: 낙인

| 항목 | 내용 |
|---|---|
| 무대 | 데드존 최외각 — 폐기물 처리장 (5×5 그리드) |
| 목표 | 허기·갈증을 버티며 구시대 지하 방공호에 닿고, 몰려오는 분쇄 기계 **스캐브 컬렉터**를 멈춰 첫 거점을 선언한다 |
| 플레이 타임 | 약 90분 |

1. **자아 부팅** — 시각 센서가 켜지고, 이동할 때마다 허기·갈증이 줄어드는 생존 루프를 익힌다
2. **행위 기록 수집** — 쓰레기 바다를 탐색하며 급조 장비를 모으고, 생존 방식을 묻는 선택(세션)을 마주한다. 선택은 물리 격돌 · 자원 정제 · 연산 침투 성향으로 쌓인다
3. **데드라인 경보** — 방공호를 찾은 순간, 스캐브 컬렉터가 안식처를 향해 돌진해 온다
4. **컬렉터 보루전과 각성** — 15턴 안에 보스를 쓰러뜨리고, 노출된 동력 코어를 어떻게 처분할지 고른다. 쌓아 온 성향과 이 선택이 직업을 결정한다

## 설치 및 실행

**Windows (권장)**
1. [릴리즈 페이지](../../releases/latest)에서 `PROTOCOL_STIGMA_win64.zip` 다운로드
2. 압축을 풀고 폴더 안의 `PROTOCOL_STIGMA.exe` 실행
3. Windows Defender 경고 시 → `추가 정보` → `실행` 선택

**macOS (Apple Silicon)**
1. [릴리즈 페이지](../../releases/latest)에서 `PROTOCOL_STIGMA_mac.tar.gz` 다운로드
2. 터미널에서 압축 해제 후 실행:

```bash
tar -xzf PROTOCOL_STIGMA_mac.tar.gz
chmod +x PROTOCOL_STIGMA
./PROTOCOL_STIGMA
```

**소스 직접 실행** (Python 3.10+)

```bash
pip install colorama pygame-ce rich
cd 개발
python Main.py
```

빌드·개발 관련 내용은 [개발/BUILD.md](개발/BUILD.md)를 참고하세요.

### 생존 메커니즘

- **HP:** VIT 기반 (기본 약 1,500). 0 이하 → GAME OVER. 되살리기나 안전 구역은 없다
- **허기 / 갈증:** 매 턴 소모. 어느 하나라도 0에 도달하면 턴당 HP 감소
- **고철 (Materials):** 탐색·분해로 수집. 소모품 구매 및 스킬 발동 비용
- **Alert Level (0~100):** 적 세력의 경계 지수. 전투 조우 시 상승, 매 턴 -3 자동 감쇄. 높을수록 전투 조우 확률 증가 (SAFE 0–39 / CAUTION 40–69 / DANGER 70–100)
- **타일 수색 한도:** 타일마다 수색 가능 횟수가 랜덤 배정됨. 소진 후 쿨타임이 지나야 재수색 가능

### 기본 능력치

각성 전(민간인 상태)에는 세 가지 능력치만 작동합니다.

| 능력치 | 효과 |
|---|---|
| **VIT (체력)** | 최대 HP, 기본 방어력, 허기·갈증 소모 감소 |
| **INT (지력)** | 사이버덱 RAM 용량 (패킷 우회·RAM 스킬 비용) |
| **DEX (민첩)** | 치명타 확률, 회피율 (후퇴 성공률) |

### 전투 시스템

전투는 턴제로 진행됩니다.

| 키 | 행동 | 설명 |
|---|---|---|
| **1** | 주무기 공격 | 장비 Power 기반 데미지 — 치명타 확률 적용 |
| **2** | 급조 바리케이드 | 방어 태세 — 이번 턴 받는 피해 반감 + 보스 학습 지수 −4 |
| **3** | 패킷 우회 교란 | RAM 2 소모 — 적 딥러닝 분석 수치 초기화 |
| **4** | 전술적 후퇴 | DEX 기반 도주 성공 확률 |
| **5** | 소모품 사용 | 인벤토리에서 회복 아이템 사용 |
| **6** | 보조 화기 | 네오 아크 AI 폐기 화기 발사 — 2회 제한, 소진 후 자동 파기 |
| **S / S1 / S2** | 스킬 사용 | 장착된 특화·보조 스킬 발동 |

**보스 — 스캐브 컬렉터:** 15턴 안에 쓰러뜨리지 못하면 패배합니다. 같은 공격을 연속하면 보스가 패턴을 딥러닝(학습 지수 E)해 내 피해가 최대 50%까지 깎이고, 보스 체력이 절반 아래로 떨어지면 공격이 1.6배 강해집니다. 바리케이드(받는 피해 반감, 학습 −4)와 패킷 우회(RAM 2, 학습 초기화)로 학습을 끊을 수 있습니다.

**난이도:** 일반 적은 진행 턴에 따라 강해지다가 20턴에서 멈춥니다(쉬움 턴당 +1% / 보통 +2% / 어려움 +3.5%). 보스는 플레이어의 공격력에 맞춰 강해집니다. 시작 장비로는 이길 수 없고, 파밍과 강화로 강해질수록 승률이 오르다가 난이도별 최대치(쉬움 약 70% · 보통 약 40% · 어려움 약 20%)에 수렴합니다.

### 장비 시스템

- **5등급:** T0 유물 · T1 기업 · T2 정제 · T3 규격 · T4 급조
- **11개 슬롯:** 주무기 / 사이버덱 / 의체부품 / 등 장비 / 얼굴 / 상의 / 하의 / 신발 / 목걸이 / 반지 / 특화부품
- **장비 획득:** 스토리 선택 보상, 일반 전투 승리(30%), 탐색 파밍(15%). 드롭 등급은 T4 80% · T3 19% · T2 1%
- **장비 분해:** 불필요 장비 → 고철 추출
- **강화:** 맵의 강화소(미니맵 호박색 칸, 판마다 위치가 다름)에서 `U`를 누르고 주무기를 고른 뒤 `R`. 고철을 써서 +1~+10까지 위력을 올린다(+10에서 +350). 성공률은 +1~3 80% · +4~6 50% · +7~9 25% · +10 10%이고, 실패해도 장비는 사라지지 않으며 실패할 때마다 다음 성공률이 오른다. 단, +8~+10에 실패하면 내구도가 10 깎이고 10~20% 확률로 한 단계 내려간다. 내구도가 떨어지면 강화 위력도 줄고(0이면 절반) 0이 되면 더 강화할 수 없으니 강화소에서 `F`로 고철을 써서 수리한다. 1막에서는 주무기만 강화할 수 있다
- **세계관 플레이버:** 장비 등급이 높아질수록 숨겨진 서사 잠금 해제

## 저장 / 로드

- **저장:** 게임 중 `C` 키 → `stigma_save.json` 자동 생성·갱신
- **로드:** 타이틀 화면 `2번(게임 불러오기)` → 이전 저장 시점부터 재개
- **항법 일지:** `J` 키로 지금까지의 선택 기록 열람
