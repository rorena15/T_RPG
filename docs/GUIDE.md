## 조작

모든 화면은 **방향키로 고르고 Enter(또는 Space)로 실행**, **마우스로 올려서 누르기**가 된다. 화면 아래 조작 안내도 버튼이다.
선택지에는 번호가 보이지 않지만 숫자키는 그대로 단축키로 동작한다. Esc는 뒤로 가기·닫기.

**맵**

| 키 | 기능 |
|---|---|
| W / A / S / D (방향키) | 한 칸 이동 (W 북 · S 남 · A 서 · D 동). 미니맵의 옆 칸을 눌러도 이동 |
| F (Space) | 지금 칸 탐색 |
| I (Tab) | 인벤토리 |
| E | 발칸 게이츠와 대화 · 강화소 (그 칸에서만) |
| J | 항법 일지 |
| 1 ~ 0 | 퀵슬롯 소모품 사용 (턴을 쓰지 않는다) |
| F5 | 저장 |
| Esc | 나가기 (저장하고 종료 / 저장 없이 종료 / 취소) |

**전투**

| 키 | 행동 |
|---|---|
| Q | 주무기 공격 |
| E | 급조 바리케이드 |
| R | 패킷 우회 교란 |
| F | 보조 화기 |
| Z / C | 스킬 1번 칸 / 2번 칸 |
| X | 전술적 후퇴 |
| I | 소모품 목록에서 골라 쓰기 |
| 1 ~ 0 | 퀵슬롯 소모품 (한 턴, 빈 칸은 턴을 쓰지 않는다) |

**인벤토리 · 강화소**

| 키 | 기능 |
|---|---|
| ↑↓ (W/S) · 휠 | 고르기 |
| Tab (Shift+Tab 거꾸로) · 탭 클릭 | 장비 슬롯 / 가방 / 소모품 탭 |
| Enter · Space · 고른 줄 다시 클릭 | 장착 · 해제 · 사용 |
| X (Delete) | 분해 (한 번 더 눌러 확인) |
| 1 ~ 0 | 소모품 탭에서 퀵슬롯 연결 (같은 번호를 다시 누르면 해제) |
| R / F | 강화 / 수리 (강화소에서만) |
| Esc · I | 닫기 |

## 생존

- **HP**: VIT 기반 (시작 약 1,500). 0이 되면 게임 오버. 되살리기나 안전 구역은 없다
- **허기 · 갈증**: 이동·탐색할 때마다 준다. 어느 하나라도 0이면 턴마다 HP가 깎인다
- **고철**: 탐색·분해·전투로 모은다. 행상인 거래, 강화·수리, 일부 스킬에 쓴다
- **경계 (0~100)**: 전투를 하면 오르고 턴마다 3씩 내려간다. 높을수록 조우가 잦고, **60 이상이면 네오 아크 청소 부대**가 끼어든다
  (안전 0–39 · 주의 40–69 · 위험 70–100)
- **타일 수색 한도**: 칸마다 2~4회. 다 쓰면 8~14턴 쉬어야 다시 뒤질 수 있다
- **게임 속 시간·날씨**: 턴이 지나면 새벽 → 아침 → 낮 → 저녁 → 밤이 돌고 (첫 턴은 아침), 날씨(스모그 · 안개 · 먼지 폭풍 · 재 · 산성비)가 몇 턴씩 이어진다. 밤·새벽에는 어두운 음악이 깔린다

## 능력치

각성 전(민간인)에는 세 능력치만 작동한다.

| 능력치 | 효과 |
|---|---|
| VIT (체력) | 최대 HP, 기본 방어력, 허기·갈증 소모 감소 |
| INT (지력) | 사이버덱 RAM (패킷 우회 · RAM 스킬 비용) |
| DEX (민첩) | 치명타 확률, 회피율, 후퇴 성공률 |

## 탐색과 이벤트

`F`로 탐색하면 다음 중 하나가 일어난다.

| 결과 | 확률 | 내용 |
|---|---|---|
| 행상인 | 8% | 고철로 소모품을 산다 |
| 전투 | 경계에 따라 | 적과 조우 |
| 랜덤 이벤트 | 20% | 선택지형 · 결과형 · 특수 아이템형. 동적 서사가 켜져 있으면 GM이 서술·판정 |
| 빈 탐색 | 30% | 분위기 기록 (동적 서사면 GM이 서술) |
| 파밍 | 나머지 | 고철 · 식량 · 식수 · 회복약, 15% 확률로 장비 |

- **돌발 퀘스트**: 탐색 중 가끔 생긴다. 기한 안에 목표(탐색·고철·처치)를 채우면 보상
- **스토리 세션**: 새 칸에 들어설 때 일정 확률로. 7개, 마지막은 방공호 문
- **랜드마크**: 멸망 전 건물(대성당 · 지하철역 · 병원 · 발전소 …)은 전용 장면과 이야기가 있다

## 전투

턴제. 내가 행동하면 적이 반격한다. 잘못 누른 키나 빈 퀵슬롯은 턴을 쓰지 않는다.

| 행동 | 효과 |
|---|---|
| 주무기 공격 (Q) | 장비 위력 기반 피해, 치명타 확률 적용 |
| 급조 바리케이드 (E) | 이번 반격 피해 절반 + 보스 학습 지수 −4 |
| 패킷 우회 교란 (R) | RAM 2 — 적 분석(학습 지수) 초기화 |
| 보조 화기 (F) | 네오 아크 AI 폐기 화기를 가지고 있을 때만. RAM 2, 두 번 쓰면 파기된다 |
| 스킬 (Z/C) | 각성 후 장착한 스킬 |
| 후퇴 (X) | DEX 기반 도주. 실패하면 피해. 도망친 적은 다음 조우 때 체력을 이어 간다 |
| 소모품 (I · 1~0) | 회복·식량·식수 사용 (한 턴, 적 반격 있음) |

**데드존의 적**

| 적 | 특징 |
|---|---|
| 오염된 스캐브 드론 | 기본 적 |
| 바이오 하운드 | 변이 기계 괴수. 빠르고 아프다 |
| 굶주린 들개 무리 | 체력은 낮지만 떼로 물어뜯는다 |
| 네오 아크 청소 부대 | 경계 60 이상에서 등장. 단단하고 아프지만 이기면 고철과 장비를 더 떨어뜨린다 |

**보스 — 스캐브 컬렉터**
- 15턴 안에 쓰러뜨리지 못하면 패배
- 같은 공격을 이어 하면 패턴을 학습(학습 지수 E)해 내 피해가 최대 50%까지 깎인다 → 바리케이드·패킷 우회로 끊는다
- 체력이 절반 아래로 떨어지면 과부하(2페이즈): 공격이 1.6배
- 보스 칸(방공호)에 들어가면 준비 화면에서 소모품을 쓰고 저장한 뒤 돌입한다

**난이도**
- 일반 적은 턴에 따라 강해지다 20턴에서 멈춘다 (쉬움 턴당 +1% · 보통 +2% · 어려움 +3.5%)
- 보스는 플레이어 공격력에 맞춰 강해진다. **시작 장비로는 이길 수 없다.** 파밍과 강화로 강해질수록 승률이 오르다가 최대치에 수렴한다
  (쉬움 약 70% · 보통 약 40% · 어려움 약 20%, 밸런스 봇 실측)

## 장비 · 강화 · 강화소

- **등급 5단계**: T0 유물 · T1 기업 · T2 정제 · T3 규격 · T4 급조
- **슬롯 11개**: 주무기 · 사이버덱 · 의체부품 · 등 장비 · 얼굴 · 상의 · 하의 · 신발 · 목걸이 · 반지 · 특화부품
- **얻는 곳**: 스토리 선택 보상, 전투 승리(30%), 탐색 파밍(15%). 드롭 등급 T4 80% · T3 19% · T2 1%
- **분해**: 필요 없는 장비 → 고철

**강화소 (발칸 게이츠의 대장간)**
- 처음부터 있지 않다. 맵 어딘가(판마다 다름)에서 스크랩 연합 대장장이 **발칸 게이츠**를 만나 "대장간 재가동" 의뢰(적 3기 처치 · 고철 40)를 마치면 그 칸에 강화소가 생긴다
- 12턴이 지나도 못 만났으면 쇠 두드리는 소리로 방향과 거리를 알려 주고, 미니맵에 흐리게 표시된다

**강화 (1막은 주무기만)**
- 강화소 칸에서 `E` → 주무기를 고르고 `R`. 고철을 써서 +1 ~ +10 (+10에서 위력 +350)
- 성공률: +1~3 80% · +4~6 50% · +7~9 25% · +10 10%. 실패해도 장비는 사라지지 않고, 실패할 때마다 다음 성공률이 오른다
- **+8 ~ +10 실패**: 내구도 −10, 10~20% 확률로 한 단계 하락
- **내구도**: 떨어지면 강화 위력도 준다 (0이면 절반, 0이면 더 강화 불가). 강화소에서 `F`로 고철을 써서 수리

## 퀵슬롯

- 1~0 열 칸. 인벤토리 소모품 탭에서 소모품을 고르고 숫자키를 누르면 연결된다 (다른 칸에 있던 건 옮겨지고, 같은 번호를 다시 누르면 해제)
- 새 게임은 시작 소모품이 1~3번에 연결돼 있다 (구형 진통제 · 건조 단백질 블록 · 탁한 정수 팩)
- 맵과 전투 화면 아래 줄에 아이콘과 남은 개수가 보인다. 마우스를 올리면 이름·효과, 눌러서도 쓴다. 다 떨어진 칸은 꺼진 화면처럼 어두워진다
- 세이브에 함께 저장된다

## 스토리 · 성향 · 각성

- 스토리 세션과 이벤트의 선택은 세 성향으로 쌓인다: **kinetic**(물리 격돌) · **scrap**(자원 정제) · **cyber**(연산 침투)
- 보스를 쓰러뜨린 뒤 동력 코어를 어떻게 처분하는지(해당 성향 +3)까지 더해 **각성** 직업이 정해진다

| 직업 | 특성 | 조건 |
|---|---|---|
| 컴뱃 포스 | 고화력 근접 전투 | kinetic 우세 |
| 메카니컬 테크 | 방어·수리·자원 활용 | scrap 우세 |
| 넷 포스 | RAM 해킹·디버프 | cyber 우세 |
| [검열 됨] | [검열 됨] | [검열 됨] 분배 |

- 엔딩: 기본 3종 + 조건을 채워야 열리는 히든 엔딩. 1막을 마치면 **2막: 파벌 선택** 티저

## 스킬

스킬은 **특화 / 특수 / 보조** 세 계층이다. 전투에서 Z(1번 칸)·C(2번 칸)로 쓴다.

### 특화 스킬 — 각성 때 직업별 2개 자동 지급 (슬롯 2)

| 직업 | 스킬 | 비용 | 효과 |
|---|---|---|---|
| 컴뱃 포스 | 유압 분쇄 | HP 15% | 다음 공격 ×1.8 + 방어력 50% 관통 |
| 컴뱃 포스 | 철제 의체 | 고철 10 | 3회 피격 피해 −40~60% (VIT 기반) |
| 메카니컬 테크 | 고철 구조체 | 고철 20 | 2턴 피해 −25% + 보스 패턴 학습 차단 |
| 메카니컬 테크 | 과부하 수리 | 고철 10 | HP 즉시 회복 (INT 기반) + RAM +1 |
| 넷 포스 | 데이터 사이펀 | RAM 2 | 이번 전투 적 ATK −30% + 매 턴 RAM +1 회수 |
| 넷 포스 | 고스트 프로토콜 | RAM 1 | 이번 턴 반격 차단 + 다음 공격 치명타율 +30% |
| *** | *** | HP 5% + RAM 1 | *** 기반 즉각 피해 + 생존 수치 소모 |
| *** | *** | 고철 10 | ***을 +10% 동시 회복 |

### 특수 스킬 — 조건을 채우면 열림

| 스킬 | 조건 |
|---|---|
| 오버클록 | 컴뱃 포스 — kinetic 누적 5+ |
| 생체 수확 | 넷 포스 — 연속 3전투 \|STR−INT\|≤3 유지 |
| 보초 인프라 | 메카니컬 테크 — 고철 구조체 3회 이상 |
| 신호 추적 | 넷 포스 — cyber 누적 5+ |
| 그리드 침입 | 넷 포스 — 패킷 우회 5회 이상 |
| 프로토콜 글리치 | *** — 특정 이벤트 연쇄 |

### 보조 스킬 — 2막 이후 이벤트·퀘스트 (슬롯 3)

| 스킬 | 효과 |
|---|---|
| 바이탈 펌프 | 전투 시작 때 HP 회복 |
| 고철 방패 | RAM → 임시 방어력 |
| 정크 캐논 | 고철 → 즉각 피해 |
| 바이오루프 | 치명타 때 HP 소량 흡수 |
| 램 응축기 | 턴 끝에 RAM +1 |
| 코드 컴파일 | 2턴 보스 패턴 학습 차단 |
| 펄스 수류탄 | 범위 피해 + 보스 E 감소 |
| 키네틱 버스트 | 이번 턴 주는 피해 +15% |
| 신경 가속 | 다음 치명타 배율 2배 |
| 보이드 시프트 | 이번 턴 이탈 100% 성공 |

## 동적 서사

- 켜 두면 탐색 중 **랜덤 이벤트와 빈 탐색**을 게임 안의 로컬 AI(GM)가 그때그때 서술하고 판정한다. 스토리 세션·전투·보스·엔딩은 대본 그대로
- 선택지 맨 아래 **"다른 방법을 시도한다…"**를 고르면 행동을 직접 써서 할 수 있다. 결과 뒤 같은 장면에서 두 번까지 이어서 행동할 수 있고, 매번 턴이 흐른다
- 인터넷 연결 없이 PC에서 돈다. 한국어 전용 (영어 모드는 대본)
- 설정: **옵션 → 동적 서사** (고품질 / 가벼움 / 끄기). 처음 켤 때 추가 데이터(가벼움 1.5GB · 고품질 4.9GB)를 받을지 묻는다. **옵션 → 추가 데이터 받기**로도 받는다
- 설치 후 첫 실행은 그래픽 준비에 수십 초 걸릴 수 있고, 그동안은 대본으로 진행된다
- Windows 전용 (macOS는 대본). 사양은 [README](../README.md#시스템-요구-사양)

## 저장 · 설정 · 기록

- **저장**: `F5` 또는 나가기 메뉴. 게임 폴더에 `stigma_save.json` (소스 실행이면 `개발/`)
- **불러오기**: 타이틀의 **동기화 복구**
- **옵션**: 언어 · BGM 음량 · 효과음 음량 · 음소거 · 텍스트 속도 · 동적 서사 · 추가 데이터 받기 · 크레딧 · 라이선스. 설정은 `settings.json`
