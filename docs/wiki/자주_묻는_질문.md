# 자주 묻는 질문

[위키 대문](Home.md)

**저장은 어떻게 하나요?**
맵에서 F5를 누르거나, Esc로 나가기 메뉴를 열어 "저장하고 종료"를 고릅니다. 보스전 직전 준비 화면에서도 저장할 수 있습니다. 세이브 파일은 하나이며 게임 폴더의 `stigma_save.json`입니다.

**불러오기는 어디 있나요?**
타이틀 화면의 "동기화 복구"입니다.

**죽으면 어떻게 되나요?**
게임 오버입니다. 결말 이름과 플레이 시간이 나온 뒤 게임이 끝납니다. 마지막으로 저장한 곳부터 다시 할 수 있습니다.

**보스를 도저히 이길 수 없습니다.**
보스 체력은 공격력에 맞춰 커지지만, 강해질수록 승률이 오릅니다. 발칸 게이츠의 강화소를 열어 주무기를 강화하고, 보스전에서는 주무기 공격 사이사이에 바리케이드와 패킷 우회를 섞어 패턴 학습을 끊어 주세요. [전투와 적](전투와_적.md) 참고.

**발칸 게이츠가 어디 있는지 모르겠습니다.**
판마다 위치가 다릅니다. 12턴이 지나면 쇠 두드리는 소리로 방향과 거리를 알려 주고 미니맵에 흐리게 표시됩니다.

**경계가 너무 높습니다.**
싸우지 않고 이동이나 탐색만 하면 턴마다 3씩 내려갑니다. 60 아래로 내려가면 청소 부대가 더 이상 끼어들지 않습니다.

**결말 기록을 처음부터 다시 모으고 싶습니다.**
게임을 끈 상태에서 게임 폴더의 `endings.json`을 지웁니다. 세이브에는 영향이 없습니다.

**한 판은 얼마나 걸리나요?**
플레이 스타일에 따라 다릅니다. 게임이 플레이 시간을 재어 엔딩과 게임 오버 화면에 보여 줍니다. 5분 넘게 입력이 없던 시간은 세지 않습니다.

**Windows에서 "PC 보호" 창이 뜹니다.**
코드 서명이 되어 있지 않아 나오는 경고입니다. "추가 정보 → 실행"을 누르면 됩니다.

**오류가 났습니다. 어떻게 제보하나요?**
게임 폴더의 `diag/`에 진단 기록(`.sdg`)이 쌓입니다. 개발자만 열어 볼 수 있는 파일이며, 버그를 제보할 때 가장 최근 파일을 함께 보내 주시면 원인을 찾는 데 도움이 됩니다.

**macOS에서 동적 서사를 쓸 수 있나요?**
아직은 지원하지 않습니다. macOS에서는 대본 이벤트로 진행됩니다.
