# 조작

[위키 대문](Home.md)

어느 화면에서든 방향키로 고르고 Enter나 Space로 실행합니다. 마우스로 눌러도 되며, 화면 아래의 조작 안내도 눌리는 버튼입니다.
선택지에는 번호가 보이지 않지만 숫자키는 단축키로 동작합니다. Esc는 뒤로 가기와 닫기입니다.

## 맵

| 키 | 기능 |
|---|---|
| W / A / S / D (방향키) | 한 칸 이동 (W 북 · S 남 · A 서 · D 동). 미니맵의 옆 칸을 눌러도 이동 |
| F (Space) | 지금 칸 탐색 |
| I (Tab) | 인벤토리 |
| E | 발칸 게이츠와 대화 · 강화소 (그 칸에서만) |
| J | 항법 일지 |
| 1 ~ 0 | 퀵슬롯 소모품 사용 (턴을 쓰지 않는다) |
| F5 | 저장 |
| Esc | 나가기 (저장하고 종료 / 저장 없이 종료 / 취소) |

## 전투

| 키 | 행동 |
|---|---|
| Q | 주무기 공격 |
| E | 급조 바리케이드 |
| R | 패킷 우회 교란 |
| F | 보조 화기 |
| Z / C | 스킬 1번 칸 / 2번 칸 |
| X | 전술적 후퇴 |
| I | 소모품 목록에서 골라 쓰기 |
| 1 ~ 0 | 퀵슬롯 소모품 (한 턴, 빈 칸은 턴을 쓰지 않는다) |

## 인벤토리와 강화소

| 키 | 기능 |
|---|---|
| ↑↓ (W/S) · 휠 | 고르기 |
| Tab (Shift+Tab 거꾸로) · 탭 클릭 | 장비 슬롯 / 가방 / 소모품 탭 |
| Enter · Space · 고른 줄 다시 클릭 | 장착 · 해제 · 사용 |
| X (Delete) | 분해 (한 번 더 눌러 확인) |
| 1 ~ 0 | 소모품 탭에서 퀵슬롯 연결 (같은 번호를 다시 누르면 해제) |
| R / F | 강화 / 수리 (강화소에서만) |
| Esc · I | 닫기 |
