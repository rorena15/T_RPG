# 저장과 설정

[위키 대문](Home.md)

## 저장과 불러오기

| 항목 | 내용 |
|---|---|
| 저장 | 맵에서 F5, 또는 Esc로 나가기 메뉴를 열어 "저장하고 종료". 보스전 직전 준비 화면에서도 저장할 수 있습니다 |
| 불러오기 | 타이틀 화면의 "동기화 복구" |
| 세이브 파일 | 게임 폴더의 `stigma_save.json` 하나 |

## 옵션

옵션은 세 묶음으로 나뉩니다. 값은 Enter나 ←→로 바꿉니다.

| 묶음 | 항목 |
|---|---|
| 소리 | 전체 · 음악 · 환경음 · 효과음 음량 (5% 단위), 음소거 |
| 화면 | 전체 화면 (F11로도 전환), 글자 크기 (보통 · 크게 · 아주 크게), 화면 흔들림, 장면 움직임 (보통 · 줄임) |
| 게임 | 언어, 텍스트 속도, 전투 속도 (보통 · 빠름 · 즉시), 자동 저장 (끔 · 10턴마다 · 5턴마다), 동적 서사, 추가 데이터 받기 |

결말 기록과 크레딧 · 라이선스도 옵션에서 볼 수 있습니다.

- 글자 크기는 이야기 칸의 서술, 선택지, 전투 기록에 적용됩니다.
- 장면 움직임을 줄이면 그림의 흐름과 안개, 먼지가 멈춥니다.
- 자동 저장은 수동 저장과 같은 세이브에 덮어씁니다. 켜 두면 보스전 직전에도 한 번 저장합니다. 기본값은 10턴마다입니다.

설정은 게임 폴더의 `settings.json`에 저장됩니다. 동적 서사 설정은 [동적 서사](동적_서사.md)에 따로 정리했습니다.

## 기록

| 기록 | 내용 |
|---|---|
| 항법 일지 (J) | 지금까지의 선택과 사건이 턴 번호와 함께 남습니다 |
| 플레이 시간 | 세이브에 누적되고 엔딩과 게임 오버 화면에 표시됩니다. 5분 넘게 입력이 없던 시간은 세지 않습니다 |
| 결말 기록 | 본 결말과 각성한 직업이 `endings.json`에 남습니다. 세이브와 별개입니다 ([결말](결말.md)) |
| 진단 기록 | 오류 추적용 `diag/*.sdg` 파일이 게임 폴더에 쌓입니다. 암호화되어 있어 개발자만 열어 볼 수 있습니다. 버그를 제보할 때 가장 최근 파일을 함께 보내 주시면 원인을 찾는 데 도움이 됩니다 |
