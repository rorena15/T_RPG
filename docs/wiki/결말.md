# 결말

[위키 대문](Home.md)

> 이 문서에는 결말 조건과 숨겨진 직업이 나옵니다. 직접 찾아보고 싶다면 읽지 않아도 됩니다.

결말은 모두 20종입니다. 1막을 끝낸 상태에 따라 정해지는 클리어 결말 12종과, 도중에 쓰러졌을 때의 게임 오버 결말 8종이 있습니다.

## 결말 기록

- 본 결말과 각성한 직업은 게임 폴더의 `endings.json`에 따로 저장됩니다. 세이브와 별개라 새 게임을 시작해도 남습니다.
- 클리어 화면과 게임 오버 화면에 결말 이름, "발견한 결말 n / 20", "각성 기록 n / 4"가 표시됩니다. 아직 보지 못한 결말은 ???로 나오고, 처음 본 결말에는 "새 결말"이 붙습니다.
- 기록을 지우려면 게임을 끈 상태에서 `endings.json`을 삭제합니다.

## 클리어 결말 (12종)

에필로그 가운데 네 줄이 결말마다 달라집니다. 조건이 여러 개 맞으면 표의 위쪽 결말이 적용됩니다.

| 순서 | 결말 | 조건 |
|---|---|---|
| 1 | 황금의 조율사 | 세 성향(kinetic, scrap, cyber)이 정확히 같아 숨겨진 직업 "황금 분할의 조율사"로 각성 |
| 2 | 벼랑 끝의 생존자 | 보스를 잡은 뒤 HP가 최대의 25% 이하 |
| 3 | 흠집 없는 귀환 | 보스를 잡은 뒤 HP가 가득 참 |
| 4 | 가장 빠른 낙인 | 55턴 안에 클리어 |
| 5 | 보이지 않는 개척자 | 보스전 직전 경계가 10 이하 |
| 6 | 고철 왕의 창고 | 남은 고철이 300 이상 |
| 7 | 추적되는 낙인 | 보스전 직전 경계가 90 이상 |
| 8 | 사냥꾼의 영토 | 처치 수 40 이상 |
| 9 | 발칸의 불씨 | 강화소 완공 |
| 10 | 끝내지 못한 의뢰 | 발칸의 의뢰를 받았지만 완공하지 못함 |
| 11 | 닫힌 대장간 | 발칸을 만났지만 의뢰를 받지 않음 |
| 12 | 개척자 | 발칸을 만나지 못함 |

- 경계는 보스전이 시작되면 40 오르므로, 판정에는 보스전 직전의 값을 씁니다.
- HP 판정은 보스를 잡은 직후가 아니라 외곽 조우까지 끝난 뒤의 값입니다. 외곽 조우에서 직접 격퇴를 고르면 HP가 달라질 수 있습니다.
- 보스는 강화 없이 이기기 어렵기 때문에 10~12번은 일부러 노려야 볼 수 있습니다.

### 결말별 요령

| 결말 | 요령 |
|---|---|
| 황금의 조율사 | 세션과 이벤트의 선택을 세 성향에 고르게 나눕니다. 코어 처분에서 +3이 더해지므로, 보스 직전에 한 성향이 다른 둘보다 정확히 3 낮아야 합니다 |
| 흠집 없는 귀환 | 보스를 잡은 뒤 외곽 조우는 회피를 고르고, 필요하면 보스전 막바지에 회복약을 씁니다 |
| 가장 빠른 낙인 | 탐색을 줄이고 발칸 의뢰와 강화에 집중합니다. 이지 난이도가 수월합니다 |
| 보이지 않는 개척자 | 보스 칸에 들어가기 전 몇 턴 동안 싸우지 않고 이동만 해서 경계를 떨어뜨립니다 (턴마다 −3) |
| 고철 왕의 창고 | 강화에 다 쓰지 말고 고철을 모아 둡니다. 장비 분해와 청소 부대 처치가 고철을 많이 줍니다 |
| 추적되는 낙인 | 보스 직전까지 전투를 계속해 경계를 높게 유지합니다 |

## 게임 오버 결말 (8종)

| 결말 | 조건 |
|---|---|
| 고철 더미 | 오염된 스캐브 드론에게 쓰러짐 |
| 하운드의 먹이 | 바이오 하운드에게 쓰러짐 |
| 들개 떼의 저녁 | 굶주린 들개 무리에게 쓰러짐 |
| 수거 완료 | 네오 아크 청소 부대에게 쓰러짐 |
| 컬렉터의 수집품 | 보스전에서 쓰러짐 |
| 학습된 패턴 | 보스전 15턴 제한을 넘김 |
| 꺼진 배터리 | 허기가 0인 채로 HP가 다함 |
| 마른 냉각수 | 갈증이 0인 채로 HP가 다함 |

## 직업 (각성 기록)

| 직업 | 조건 |
|---|---|
| 컴뱃 포스 | kinetic이 가장 높음 |
| 메카니컬 테크 | scrap이 가장 높음 |
| 넷 포스 | cyber가 가장 높음 |
| 황금 분할의 조율사 | 세 성향이 정확히 같음 |
