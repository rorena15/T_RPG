# 결말

[위키 대문](Home.md)

1막의 결말은 모두 20종입니다. 끝까지 살아남았을 때의 결말이 12종, 도중에 쓰러졌을 때의 결말이 8종입니다. 어떤 결말을 보게 될지는 플레이 방식에 따라 달라지며, 조건은 게임 안에서 직접 찾아보도록 공개하지 않습니다.

## 결말을 가르는 것

1막을 끝냈을 때의 상태가 결말을 정합니다. 다음과 같은 것들이 영향을 줍니다.

- 보스를 쓰러뜨린 뒤의 몸 상태
- 방공호에 닿기까지 걸린 시간
- 네오 아크의 감시망에 얼마나 눈에 띄었는지
- 데드존에서 무엇을 얼마나 모았는지
- 발칸 게이츠와 어떤 관계로 헤어졌는지
- 세 성향이 어떻게 쌓였는지

게임 오버에도 결말 이름이 붙습니다. 무엇에 쓰러졌는지에 따라 이름이 달라집니다.

## 결말 기록

- 클리어 화면과 게임 오버 화면에 이번 결말의 이름과 "발견한 결말 n / 20", "각성 기록 n / 4"가 표시됩니다.
- 아직 보지 못한 결말은 ???로 나오고, 처음 본 결말에는 "새 결말"이 붙습니다.
- 타이틀의 **옵션 → 결말 기록**에서 지금까지 본 결말과 각성을 언제든 다시 볼 수 있습니다.
- 기록은 게임 폴더의 `endings.json`에 따로 저장됩니다. 세이브와 별개라 새 게임을 시작해도 남습니다.
- 기록을 지우려면 게임을 끈 상태에서 `endings.json`을 삭제합니다.
