## 새 게임

타이틀에서 새 게임을 고르면 난이도를 선택합니다.

| 난이도 | 일반 적 성장 (턴당, 20턴까지) | 보스전 승률 (충분히 준비했을 때, 밸런스 봇 실측) |
|---|---|---|
| 이지 | +1% | 약 70% |
| 노멀 | +2% | 약 40% |
| 하드 | +3.5% | 약 20% |

프롤로그가 끝나면 데드존 남쪽 끝의 고철 처리장 어귀에서 시작합니다. 목적지인 방공호의 위치는 지도에 나오지 않고, 오른쪽 위 머리말에 방향만 신호로 잡힙니다. [탐색과 생존](탐색과_생존.md#방공호-찾기) 참고.

## 시작 상태

| 항목 | 값 |
|---|---|
| HP | 약 1,500 (VIT에 따라) |
| 허기, 갈증 | 100 / 100 |
| 고철 | 0 |
| 소모품 | 구형 진통제 2, 건조 단백질 블록 2, 탁한 정수 팩 2 (퀵슬롯 1~3번에 연결됨) |
| 능력치 | VIT, INT, DEX만 작동하는 민간인 상태 |

## 기본 조작

| 맵 | | 전투 | |
|---|---|---|---|
| W A S D | 이동 | Q | 주무기 공격 |
| F | 탐색 | E | 바리케이드 |
| I | 인벤토리 | R | 패킷 우회 |
| E | 발칸 게이츠, 강화소 | F | 보조 화기 |
| J | 항법 일지 | Z / C | 스킬 |
| 1 ~ 0 | 퀵슬롯 | X | 후퇴 |
| F5 | 저장 | I | 소모품 |

어느 화면에서든 방향키와 마우스로 고를 수 있습니다. 선택지에 번호는 보이지 않지만 숫자키도 단축키로 동작합니다. 전체 조작은 [조작](조작.md)에 있습니다.

## 처음 30턴

1. 가까운 지점부터 탐색(F)하며 고철과 식량을 모읍니다. 지점마다 탐색 횟수가 4~7회로 정해져 있으니, 다 쓰면 이어진 길(W·A·S·D)로 옮깁니다. 길이 길수록 허기와 갈증이 더 줄어듭니다.
2. 장비를 얻으면 인벤토리(I)에서 바로 장착합니다. 쓰지 않을 장비는 분해해 고철로 바꿉니다.
3. 발칸 게이츠를 찾습니다. 12턴이 지나도 만나지 못하면 쇳물 냄새로 방향과 거리를 알려 줍니다.
4. 발칸의 의뢰(적 3기 처치, 고철 40)를 마쳐 강화소를 엽니다. 시작 장비로는 보스를 이길 수 없으므로 주무기 강화가 사실상 필수입니다.
5. 허기나 갈증이 30 아래로 떨어지면 먹고 마십니다. 0이 되면 턴마다 HP가 50씩 줄어듭니다.
6. 전투를 많이 하면 경계가 오릅니다. 60을 넘으면 네오 아크 청소 부대가 끼어들기 시작합니다.
7. 준비가 되면 방공호로 갑니다. 보스전 직전에 소모품을 쓰고 저장할 수 있습니다.
