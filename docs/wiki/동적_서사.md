# 동적 서사

[위키 대문](Home.md)

## 무엇이 달라지나

동적 서사를 켜면 탐색 중의 랜덤 이벤트와 빈 탐색을 게임 안의 로컬 AI(GM)가 그때그때 새로 서술하고 판정합니다. 같은 장소라도 판마다 다른 이야기가 나옵니다.

스토리 세션, 전투, 보스, 엔딩은 동적 서사를 켜도 대본 그대로 진행됩니다.

## 직접 행동하기

GM이 낸 선택지 맨 아래의 "다른 방법을 시도한다…"를 고르면, 하고 싶은 행동을 직접 써서 할 수 있습니다. GM이 결과를 서술하고 판정(획득, 피해, 경계 변화 등)을 내립니다. 같은 장면에서 두 번까지 이어서 행동할 수 있고, 행동할 때마다 턴이 흐릅니다.

## 설정

| 모드 | 추가 데이터 | 설명 |
|---|---|---|
| 고품질 | 4.9GB | 서술이 가장 자연스럽습니다. 그래픽 메모리가 넉넉한 PC용 |
| 가벼움 | 1.5GB | 사양이 낮은 PC용 |
| 끄기 | 없음 | 대본 이벤트로 진행 |

- **옵션 → 동적 서사**에서 고릅니다. 처음 켤 때 추가 데이터를 받을지 묻고, **옵션 → 추가 데이터 받기**로도 받을 수 있습니다.
- 설치 뒤 첫 실행은 그래픽 준비에 수십 초가 걸릴 수 있습니다. 그동안은 대본으로 진행됩니다.
- 인터넷 연결 없이 PC 안에서만 동작합니다.
- 현재 한국어, Windows에서만 지원합니다. 영어 모드와 macOS는 대본으로 진행됩니다.

사양은 [README](../../README.md#시스템-요구-사항)의 동적 서사 표를 참고해 주세요.
