# 기록 보관소 원고

고친 뒤 `개발/`에서 `python tools/archive_text.py import`로 게임에 반영한다.
`###` 줄의 키(| 앞)와 ``` 줄은 건드리지 않는다. 제목·이름(| 뒤)과 블록 안 글은 자유롭게 고친다.
확정한 글 42편은 빠져 있다 (docs/기획/기록보관소_확정.txt).

## 적 도감

기록 1 = 처음 만남, 기록 2 = 처음 이김, 기록 3 = 10번 이김 (컬렉터는 3번)

### drone | 오염된 스캐브 드론

#### 기록 1
```text
고철 시세 장부 (드론 칸)
드론 몸통 작은거 = 물 한컵
드론 몸통 큰거 = 물 한컵반 (전엔 두컵 쳐줬는디)
메인보드 쪼가리 = 물 반컵 깨진건 안쳐줌
날개 프로펠라 = 물 한컵
메모. 이놈들은 떼로 온다구 하드만 해 지고나면 더 많이 뜬다는겨. 겉은 번들번들헌디 속에 시커먼 기름이 끼어서 오염됬다고들 하드라. 쓸고 다니는 소리가 징징 난다는디 나는 귀가 어두워서 모르겄다. 값 깎자는 손님 오늘도 왔슈 빈손으로 와서 입만 살어갖구
```

#### 기록 2
```text
드론 칸 (이어서)
몸통 장갑판 = 물 두컵 찌그러진건 한컵
구리선 한뭉치 = 물 두컵반 (지난달보다 내림)
배터리 셀 = 물 두컵 터진건 안 받어
센서 눈알 = 물 한컵
메모. 손님이 허는 말이 이놈들은 뭉쳐 있을때 한꺼번에 때려야 한다는겨 한마리씩 상대하믄 옆에서 달라든다구. 그건 나두 아는디 말이 많어. 장갑 밑에 연결부가 약해서 칼끝으로 쑤시믄 된다구 한다. 터진 배터리 갖구와서 값 쳐달라는 인간은 내쫒었다. 터진거에 물을 왜 줘 내가 미쳤간
```

#### 기록 3
```text
드론 칸 (또 이어서)
몸통 작은거 = 물 한컵 어제는 반컵이었는디 또 올랐네
메인보드 쪼가리 = 물 한컵 요새 귀해졌다
메모. 장사 한지 이십년이 넘었는디 드론 값이 이리 오르락내리락 허는건 첨이여. 비오는 날엔 더 몰려 나온다구 해서 비 오믄 가게문 닫구 들어앉어 있는다. 쓸만한 놈은 젊은것들이 다 주서가서 나헌텐 찌그러진거만 온다. 무릎이 쑤시는걸 보니 오늘두 비오겄다. 외상은 안된다구 몇번을 말햐 외상값 안갚구 간 놈 이름 적어둔다 ****
```
