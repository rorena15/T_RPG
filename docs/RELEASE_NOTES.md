# PROTOCOL: STIGMA v2.0.0

1막 「낙인」 데모 버전입니다. 플레이 시간은 90분 정도이고 결말은 모두 20종입니다.

## 바뀐 점

### 화면과 동적 서사

- 탐색, 이벤트, 전투, 인벤토리를 그림이 들어간 화면으로 바꿨습니다. 장면 그림은 160장 정도이고 깊이에 따라 조금씩 움직입니다.
- 동적 서사(Windows, 선택 사항): 켜 두면 로컬 AI가 탐색 중 이벤트를 매번 새로 쓰고 판정합니다. 못 쓰는 환경에서는 원래 대본으로 진행됩니다.
- 오프닝을 넣었습니다.
- 미니맵을 2.5D로 바꿨습니다. N-404의 시각 센서로 보는 화면입니다.
- 칸을 이동할 때 장면이 자연스럽게 전환되는 연출을 추가했습니다.
- 보스전 준비, 코어 선택, 방공호 외곽 조우, 2막 예고도 그림이 들어간 화면으로 바꿨습니다. 동적 서사를 꺼도 탐색 이벤트가 같은 화면으로 나옵니다.

### 조작

- 키 배치를 바꿨습니다. 이동 WASD, 탐색 F, 인벤토리 I, 일지 J, 저장 F5, 강화소 E, 뒤로 Esc
- 전투 키: Q 공격, E 바리케이드, R 패킷 우회, F 보조 화기, Z/C 스킬, X 후퇴, I 소모품
- 모든 화면을 방향키와 마우스로 조작할 수 있습니다. 미니맵 옆 칸을 눌러서도 이동됩니다.
- 퀵슬롯 1~0을 추가했습니다. 인벤토리 소모품 탭에서 숫자키로 등록하고, 맵에서는 턴을 쓰지 않고 바로 씁니다.
- 퀵슬롯과 전투 버튼에 아이콘을 넣었습니다.
- 선택지 번호를 화면에서 뺐습니다. 숫자키는 그대로 됩니다.
- 전투 기록에는 방금 주고받은 공방만 남습니다. "아무 키나 누르면 진행" 안내는 기다리는 동안만 표시됩니다.
- 나가기 메뉴에 취소를 추가했고, 인벤토리 탭은 Tab 키로 전환합니다.

### 강화소

- 고철을 사용해 주무기를 +10까지 강화할 수 있습니다. 실패해도 무기는 사라지지 않으며, 실패할 때마다 다음 성공 확률이 오릅니다.
- +8 이상에서 실패하면 내구도가 감소하고, 일정 확률로 강화 단계가 한 단계 내려갑니다. 내구도는 강화소에서 고철로 수리할 수 있습니다.
- 강화소는 처음부터 이용할 수 없습니다. 맵 어딘가에 있는 대장장이 발칸 게이츠의 의뢰(적 3기 처치, 고철 40)를 완료하면 열립니다. 오랫동안 찾지 못하면 쇠를 두드리는 소리로 방향을 알려 줍니다.

### 성향, 적, 탐색

- 성향(완력, 해체, 해킹)이 2, 4, 6에 닿을 때마다 그 자리에서 능력을 얻습니다. 완력은 주무기 피해, 해체는 고철 획득과 바리케이드·자가 수리, 해킹은 패킷 우회 비용과 반격 차단, RAM 회수에 영향을 줍니다.
- 적마다 고유한 행동이 생겼습니다. 드론은 장갑판을 올려 공격을 튕겨 내고, 바이오 하운드는 한 번 더 물고, 들개 무리는 수가 줄수록 약해지며, 청소 부대는 증원을 부릅니다. 증원 신호는 패킷 우회로 끊을 수 있습니다.
- 칸마다 위험도가 있습니다. 위험한 칸일수록 적을 자주 만나지만 고철과 장비가 더 많이, 더 좋게 나옵니다. 미니맵에 눈금으로 표시됩니다.
- 여러 번 다 뒤진 칸은 건질 것이 줄어듭니다. 새로운 칸을 찾아 옮겨 다니는 편이 유리합니다.
- 결말을 20종으로 늘렸습니다. 1막을 마친 상태에 따라 결말이 갈리고, 본 결말은 따로 기록되어 새 게임에서도 남습니다.

### 전투와 밸런스

- 보스는 시작 장비로는 이길 수 없습니다. 장비를 모으고 강화할수록 승률이 오르며, 난이도별로 쉬움 약 70%, 보통 약 40%, 어려움 약 20%에 수렴합니다.
- 장비 드롭을 추가했습니다 (전투 승리 30%, 탐색 15%).
- 새 적을 추가했습니다: 굶주린 들개 무리, 네오 아크 청소 부대 (경계 60 이상에서 등장하며, 처치 시 고철과 장비를 더 많이 얻습니다).
- 일반 적은 20턴까지만 강해집니다.

### 사운드

- BGM이 끊기거나 급하게 전환되던 문제와 음량 설정 버그를 수정했습니다. 곡이 바뀔 때 부드럽게 이어집니다.
- 타이틀, 보스전, 밤 탐색, 엔딩 음악을 넣었습니다.
- 무기 종류별, 적 종류별 공격음과 강화, 탐색, 메뉴, 선택 결과 효과음을 넣었습니다.
- 날씨별 환경음(스모그, 안개, 먼지 폭풍, 재, 산성비)을 넣었습니다.
- 음량을 전체, 음악, 환경음, 효과음으로 나눠 5% 단위로 조절할 수 있습니다. 옵션에서 ←→로 바꿉니다.
- 음량 50% 이상이 모두 같은 크기로 나던 문제를 고쳤습니다.
- 옵션을 소리, 화면, 게임으로 나누고 전체 화면, 글자 크기, 화면 흔들림, 장면 움직임, 전투 속도, 자동 저장을 추가했습니다.
- 옵션에 크레딧 · 라이선스 메뉴를 넣었습니다.
- 옵션에 결말 기록을 넣었습니다. 지금까지 본 결말과 각성을 볼 수 있습니다.

### 언어

- 영어를 전면 지원합니다 (장비 463종 포함).

## 버그 수정

- 전투에서 잘못된 키를 눌러도 적이 반격하던 문제
- 바리케이드가 피해를 줄이지 못하던 문제
- 타일 수색 횟수 제한이 빠져 있던 문제
- 게임 오버 문구가 깨지던 문제, 작은 화면에서 창이 잘리던 문제
- 동적 서사 결과 형식이 틀리면 멈추던 문제
- 보조 화기가 S로 표시돼 누르면 스킬이 나가던 문제
- 종료 확인에서 Y 말고 다른 키를 누르면 저장 없이 꺼지던 문제
- 인벤토리 분해 키(D)가 탭 이동과 겹치던 문제 (분해는 X로 바꿈)
- 맵에서 지정되지 않은 키를 누르면 "이동 불가"가 표시되며 멈추던 문제

## 다운로드

| 플랫폼 | 파일 | |
|---|---|---|
| Windows 64비트 | `PROTOCOL_STIGMA_win64.zip` | 압축을 풀고 exe 실행 |
| Windows (1.9.x 자동 업데이트용) | `PROTOCOL_STIGMA.exe` | 이전 버전의 업데이터용 |
| macOS (Apple Silicon) | `PROTOCOL_STIGMA_mac.tar.gz` | 터미널에서 실행 |

코드 서명이 되어 있지 않아 실행 시 경고가 표시될 수 있습니다. Windows는 **추가 정보 → 실행**, macOS는 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택해 주세요.

## 알려진 문제

- macOS는 자동 업데이트를 지원하지 않습니다. 릴리스 페이지에서 직접 내려받아 주세요.
- 동적 서사는 현재 Windows에서만 지원합니다. macOS 지원은 준비 중입니다.
- 클리어 뒤의 에필로그와 게임 오버 화면은 아직 이전 방식의 텍스트 화면으로 표시됩니다.

자세한 규칙과 수치는 [위키](wiki/Home.md)를 참고해 주세요.
