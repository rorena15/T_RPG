# 정면 뷰 기획 방향 (v2.1 후보)

풀 2.5D·3D 대신, 칸마다 **정면 배경 그림을 화면 가득** 깔고 UI를 아래로 물린 1인칭 정면 뷰.
2.0.0 게임 화면(왼쪽 장면 판 + 오른쪽 글 칸)은 그대로 두고, 게임 코드와 상관없이 그린 목업이다.

## 채택: 최소 HUD (`채택_*.jpg`)

| 파일 | 장면 |
|---|---|
| 채택_1_탐색_최소HUD.jpg | 탐색 — 네오 아크 외벽, 밤 |
| 채택_2_전투_최소HUD.jpg | 전투 — 스캐브 드론 |
| 채택_3_대화_최소HUD.jpg | 대화 — 발칸 게이츠 (대장간) |

원칙
1. 그림이 화면의 2/3 이상. UI는 아래 띠(기록 · 행동 · 지표 · 퀵슬롯 · 조작)와 왼쪽 위 제목만.
2. 패널 박스 없이 어두운 그라데이션 위에 글자를 바로 얹는다. 고른 것에만 주황 테두리.
3. 미니맵은 작게(오른쪽 위), 크게 보는 키를 따로 (예: M).
4. 톤은 N-404 시각 센서: 주황 단색 아이콘, 주사선, 잡음, 모서리 꺾쇠. 빛 번짐(네온)은 쓰지 않는다.

## 비교안 (`비교안/`)

정보를 화면 곳곳에 배치한 패널형. 채택안과 비교용으로 남긴다.
랜드마크 발견 띠(1), 비주얼 노벨식 이름표(2), 행상인 목록(3), 체력 위기 붉은 가장자리(4), 보스 학습 지수 게이지(5)는 채택안에도 가져다 쓸 수 있는 요소.

## 선행 작업

- **적 그림 새로 뽑기 (가장 중요)**: 지금 교전 그림(`assets/scenes/enemy_*`)은 흐리고 뭉개져서 화면 가득 키우면 적이 형체가 없다.
  가로 비율로, 적이 가운데에 선명하게 서 있게 SDXL로 다시 뽑는다 (드론 · 바이오 하운드 · 들개 · 청소 부대 · 컬렉터).
- 배경은 지금 세로 그림(600×1050)을 잘라 키운 것이라 조금 흐리다. 가로·정사각 비율로 다시 뽑으면 좋다.
- 조준 꺾쇠는 적이 그림 어디에 있는지 알아야 하므로, 적 그림마다 위치 값을 둔다.

## 다시 그리기

`mockup.py`는 게임의 그리기 도구(MapView, 퀵슬롯, 센서 아이콘)를 빌려 목업을 그린다. `개발/` 폴더에서 실행:

```
SDL_VIDEODRIVER=dummy python ../기획/정면뷰_목업/mockup.py 출력_접두어
```
